# Product labels

Use [CONTEXT.md](../CONTEXT.md) for domain meanings. These conventions apply to
visible labels, accessible names, help text, and both supported languages.
Translation keys and wire names may retain historical wording.

- Use sentence case for headings, fields, and actions. Preserve product names
  and the role titles defined in the glossary.
- Name surfaces consistently: Home, Threads, Tasks, Automations, Projects,
  Agents, Teams, Computers, Skills, Settings, and Admin console.
- Use **New task** (or another object) to open a creation form, **Create task**
  to submit it, and **Save task** to save edits. Use **Add agent** when adding
  an existing agent to a project or team.
- Use **Connect computer** for personal computer enrollment and **Create
  computer** for provisioning admin hardware. Use **Local computer** and
  **Cloud computer** for the two types.
- Use **Choose** for a single choice and **Select** for multi-selection or a
  native file picker. Keep placeholders brief; put examples in input fields.
- Use **Status**, not State. Task statuses are Backlog, Ready, Running,
  Waiting for you, In review, Blocked, and Completed. **Needs attention**
  groups actionable work; it is not a stored task status.
- Use **Start** to begin task work, **Run now** for an automation, **Retry**
  to run work again, and **Try again** to retry loading or saving. Preserve
  the distinction between Stop, Cancel, Delete, Disconnect, and Remove.
- Use **Request changes** for review feedback. Use **Accept** for task
  acceptance and **Approve** for a held team step. Permission prompts retain
  their separate Allow and Deny actions.
- Call Codex, Claude Code, Pi, OpenCode, and Kimi **agent runtimes**. A runtime
  executes an agent; it is not an agent identity. Keep Placement where the
  binding itself is being managed.
- Use **Prerequisites** for tasks that must finish first, **Waiting on** for
  that list, and **Enables** for the tasks that follow.
- Name destructive actions and retain their scope and consequences in the
  confirmation. Do not shorten away irreversibility, lost history, or effects
  on active work.
- Keep interpolation variables and plural forms intact. Update English and
  Simplified Chinese together, including eager public English copy when its
  source strings change.
